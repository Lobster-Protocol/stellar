# DecisionTaker API

Minimal TypeScript Express API.

## Setup

1. Copy env file:
   ```bash
   cp .env.example .env
   ```
2. Install deps:
   ```bash
   npm install
   ```

## Commands

- Dev server:
  ```bash
  npm run dev
  ```
- Build:
  ```bash
  npm run build
  ```
- Start (after build):
  ```bash
  npm start
  ```

## Endpoints

- `GET /` → basic status
- `GET /health` → health check
